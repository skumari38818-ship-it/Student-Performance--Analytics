# Student Performance & Dropout Risk Analytics

A data analytics project focused on analyzing student performance, dropout risk, and placement outcomes using Excel and Power BI.

## Project Overview
This project analyzes student performance, attendance, engagement, wellbeing, and dropout risk using Microsoft Power BI. The dashboard helps educational institutions identify at-risk students and make data-driven decisions.

## Problem Statement
Educational institutions generate large amounts of student data. Without proper analysis, it is difficult to identify students with poor attendance, low academic performance, high stress levels, or a high risk of dropping out.
